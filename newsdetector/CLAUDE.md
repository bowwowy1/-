# CLAUDE.md — 뉴스감지기 작업 기준

이 프로젝트에서 작업할 때 반드시 지켜야 할 기준을 요약한다.

## 기준 문서
- 이 프로젝트의 기준 문서는 `docs/` 폴더다.
- 작업을 시작하기 전에 항상 아래 세 문서를 먼저 읽는다.
  - `docs/channel.md` — 채널 정체성과 벤치마킹 원칙
  - `docs/script_rules.md` — 대본 규칙
  - `docs/sourcing.md` — 소재 발굴 규칙

## 폐기된 옛 기준
- 옛 기준(7단락 구조, 반박 단락, 535~580자 분량 등)은 폐기되었다.
- 폐기된 기준은 어떤 결정에도 다시 쓰지 않는다.

## 사실 경계
- 평가와 프레임은 세게 써도 된다. (참교육, 박살, 딱 걸렸다 등)
- 그러나 숫자(금액, 비율, 건수, 기간)와 인과("~때문에", "~덕분에", "~해서")는
  반드시 기사로 확인된 것만 쓴다.
- 확인되지 않은 통계, 추정된 인과, 부풀린 숫자는 금지한다.

## 단계 순서
1. 1단계: 프로젝트 뼈대와 문서
2. 2단계: `config/` yaml 채우기 (분량 TBD 확정 포함)
3. 3단계: `src/validator.py` 구현 (대본 린터)
4. 4단계: `src/scorer.py` 구현 (소재 채점기)
5. 5단계: 기존 `collector.py` 를 `src/collector.py` 로 연결

## 작업 범위 규칙
- 사용자가 요청한 단계 밖의 파일은 수정하지 않는다.
- 각 단계의 완료 조건이 명확할 때만 다음 단계로 넘어간다.
