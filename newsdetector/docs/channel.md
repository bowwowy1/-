# 채널

- 이름: 뉴스감지기 / 정치·시사 숏츠 / 시청층 40~70대 / 친이재명 성향
- 현재 구독자 약 600명. 벤치마킹 대상은 구독자 27만의 "정치한줄"이다.

## 벤치마킹 원칙
- 정치한줄의 공식을 거의 그대로 따라간다. 27만 채널이 검증한 공식이라 뜯어고치지 않는다.
- 톤도 정치한줄만큼 세게 간다. "참교육", "박살", "딱 걸렸다", "기가 막힌", "칼을 빼 들었다" 같은 감정 단어와 속 시원한 마무리를 유지한다.
- 결과를 첫 문장에 먼저 던진다. 결론을 뒤로 미루지 않는다.

## 차별점 (딱 세 가지)
1. 고정 문구
   - 오프닝: "이거 사실이야?"
   - 전환: "무슨 내용인지 바로 알려줄게"
   - CTA: "~면 구독과 좋아요 부탁하고 여러분의 생각을 댓글로 남겨주세요"
2. 반전 자리에 "이건 몰랐지?" 한 줄을 넣는다.
3. 사실 경계: 숫자와 인과는 기사로 확인된 것만 쓴다. 없는 통계, 확인 안 된 인과, 부풀린 숫자는 금지한다. 프레임과 평가 표현은 제한하지 않는다.

## 저작권
- 영상 소스는 저작권이 있으므로 출처(JTBC·MBC) 표기를 유지한다.
