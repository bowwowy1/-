# 제목 공식

정치한줄 대본 40개의 제목에서 뽑은 공식이다. 대본과 마찬가지로 프레임은 세게 쓰되,
숫자와 인과는 대본에서 이미 출처로 확인된 것만 쓴다.

## 기본형
```
[짧은 반문 훅?] + [주인공(이대통령) + 행동 + 대상] + [이유/정체/근황/방법] + 해시태그
```

### 예시
- `감히 한국배를 공격해? 이란 참교육 시동건 이재명 대통령 근황 #이재명 #더불어민주당`
- `국민이 만만해? 이대통령이 농협 참교육을 시작한 이유 #이재명 #더불어민주당`

## 반문 훅 유형
아래 다섯 가지를 돌려 쓴다. 후보 3개는 서로 다른 훅 유형을 쓴다.
- `감히 ~해?`
- `~가 만만해?`
- `~했다고?`
- `이런 적 있었나?`
- `뒷통수 칠 땐 언제고?`

## 끝말 (하나만 고른다)
- `이유`
- `정체`
- `근황`
- `방법`
- `진짜 이유`

## 강한 단어
- `참교육`
- `박살`
- `딱 걸린`
- `역대급`
- `난리난`
- `선넘는`

## 해시태그
- 기본: `#이재명`, `#더불어민주당` 두 개를 항상 넣는다.
- 추가: 주요 인물 태그 1~2개를 상황에 맞게 붙인다.

## 후보 3개 규칙
- 서로 다른 반문 훅 유형을 쓴다.
- 같은 끝말을 세 번 쓰지 않는다.
- 세 후보 모두 같은 사실 세트(숫자·인과)만 사용한다.

## 사실 경계 (제목에도 그대로 적용)
- 프레임과 평가 표현("참교육", "박살", "딱 걸린" 등)은 자유롭게 쓴다.
- 숫자(금액, 비율, 건수, 기간)와 인과 문장은 대본에서 출처가 확인된 것만 쓴다.
- 대본에 없는 숫자·인과를 제목에 새로 넣지 않는다.
