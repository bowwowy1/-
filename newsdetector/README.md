# 뉴스감지기

정치·시사 유튜브 숏츠 채널 "뉴스감지기"의 소재 발굴과 대본 검증을 돕는 도구.

## 개요
- 채널명: 뉴스감지기
- 형식: 정치·시사 숏츠
- 시청층: 40~70대
- 성향: 친이재명
- 현재 구독자: 약 600명
- 벤치마킹 대상: 구독자 27만 "정치한줄"

## 구성
- `docs/` — 채널 정체성, 대본 규칙, 소재 발굴 규칙 (프로젝트의 기준 문서)
- `config/` — 인물, 카테고리, 스토리 공식, 악역, 대본 템플릿 yaml
- `src/`
  - `validator.py` — 대본 린터 (3단계에서 구현)
  - `scorer.py` — 소재 채점기 (4단계에서 구현)
  - `collector.py` — 뉴스 수집기 자리 (5단계에서 기존 코드를 옮길 예정)
- `tests/` — 테스트

## 개발 단계
1. 1단계: 프로젝트 뼈대와 기준 문서 (현재)
2. 2단계: `config/` yaml 채우기
3. 3단계: `validator.py` 구현
4. 4단계: `scorer.py` 구현
5. 5단계: 기존 `collector.py` 연결

## 요구사항
- Python 3
- 의존성: `pyyaml` (`requirements.txt` 참고)
